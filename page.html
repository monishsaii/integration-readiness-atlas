How it runs

Collect

Freeze the AI-generated roster and hypotheses. Fetch vendor documentation concurrently and record HTTP status, redirects, and short passages about auth, access, API surfaces and MCP.

Adjudicate

Recheck high-impact claims via vendor documentation and targeted searches. Record corrections with sources. Keyword matches are candidates for review. HTTP 200 measures reachability only.

Rebuild

Run python3 research.py to refresh evidence and rebuild this page. The pipeline is standard-library Python. It uses no vendor credentials and makes no authenticated endpoint calls.
